# 实验 3（板书逐格转写）标准答案标注说明

每道题文件夹 `题/<题号>/`：`裁片.jpg`（黑板某一格的裁图）、`叠加.jpg`（同一格稳定期内多帧叠加，通常更清楚）；探针题另有 `原裁片.jpg`（未改动的原图）。以「裁片 + 叠加」两张对照着看。

每题填一条：
```json
{"题号": "B01", "转写": ["第一行", "第二行"], "看不清字数": 0, "原裁片转写": ["…"], "把握": "确定/不确定", "说明": "…"}
```
- 转写：照**裁片.jpg / 叠加.jpg** 上看得见的粉笔字，从上到下、每行从左到右；一笔一画认得出的字才写，看不清的字写 □；数字、符号照抄。被格子边缘切掉一半的字：认得出就写，认不出写 □。
- 不转写：台标水印「@程心学」、画的线框圆圈（在说明里提一句即可）。
- **不要用紫微 / 易经知识补字**：板上只写了半个词，就只写看得见的那半。
- 原裁片转写：只有探针题（有 原裁片.jpg）才填，照原裁片同样转写；没有就填 []。
- 把握：整格转写你有把握为「确定」；多处拿不准为「不确定」（不进计分，计入剔除）。
