## 2026-11-08 晚　叠图预处理

1. 找叠图：全片每秒 1 帧打分，53,491 秒里 15,586 秒有叠图（29.1%）；有三集完全没有。
2. 切状态、去重：2,645 个叠图状态，去重后 1,580 张要转写（`scripts/叠图/overlay_states.py`）。
3. Claude Opus 5.5（xhigh）**两遍独立转写**（第二遍加「繁体照抄」），约 $169。
4. 两遍逐格逐字比对：字级一致 96.4%；对不上的 897 处，两种读法匿名成甲乙，**第三次看原图裁定**（接口 59 张 + Opus 子代理 408 张）。裁定结果：第一遍对 303、第二遍对 449、两遍都不对 145——只做一遍会漏。
5. 定稿：两遍一致 1,921、裁定 703、单遍＋逐字核对 21；看不清写 □ 的占 0.92%。抽检 24 张：22 全对、2 处繁体写成简体。详见 `叠图定稿说明.md`。

踩过的坑：流式接口并发 32 时大量「连接被对端断开」，并发降到 8–12、每张重试 3 次才稳；脚本必须逐条落盘（一次整轮崩溃丢了已付费的结果）；模型输出的 JSON 偶有全角逗号。

## 2026-11-08 晚　粉笔字还能怎么救

- Claude xhigh 把小考的 30 格板书重做两遍：认得出的部分与标准答案一致 77–85%，但多认出来的字两遍只有 46% 一样——**开高档思考也变不出像素里没有的字**。
- 三路证据小测第一版（`scripts/第0步/chalk_evidence.py`）：拿「这格字附近说的话」当旁证，认得出的字里 32–47% 能在口述 / 叠图里找到，但换一段无关的语音也有 21–32% 碰巧对上——**旁证力很弱**。原因之一：镜头经常平移，按固定九宫格切出的「板面格」前后不是同一块黑板。
- 用叠图反推命例生辰、还原整盘（`scripts/命例反推/solve.ts`）：45 个命例组里多数分组混了两个命例；能对上的组有 4 组星名全对，但都有并列解。分组方法待改。
- 结论：权威信息以**电子叠图（已定稿）+ 口述**为主；粉笔字只照录看得清的、标明证据，认不出的不补，交付时公布比例。

## 2026-11-08 夜　复查与重测

- **叠图去重漏洞**：剪辑常把同一格只改宫名来举例（如「子女 庚辰」→「命宫 癸未」），原去重按整块平均差判断，把它们并成了重复。改成按小块取最大差（`overlay_recheck.py`）：真重复的块差 3–12，误并的 43–137，阈值定 25。全量复查标出 255 个可疑重复、322 个状态内有变化（含彩框、箭头这类非文字变化，需再分）。
- **苹果系统文字识别（Vision）交叉核对**（`scripts/vision_ocr/`、`overlay_vision2.py`、`vision_compare.py`）：和 Claude 完全不同的技术，用来抓「两遍都是 Claude、同错查不出」的漏洞。它按横行读字，竖排星名会被拆开、读不全，所以只用它抓定稿可能的错漏，不用它证明定稿完整。
  - 第一版裁小块再识别：彩框把叠图切碎、窄块读不出，只读到定稿的 39%，作废。第二版整帧识别、只留叠图范围的字：读到定稿字的 49.4%。
  - 苹果有把握读出、定稿里却没有的字 ≥ 2 个的有 122 张：其中有真漏（如一张完整 12 宫盘定稿只录了 283 字，苹果读出 632 字），也有面相图上的宫名标签（定稿按设计没收，要补）和误读进来的字幕（噪声）。待逐张看原图处理。
  - 用它复核去重不行：同一张叠图隔几秒再截，读出的字也会变，太不稳定。去重以分块比对为准。
- **指代层 Kimi 重测**（同一批 52 道确定题，门槛不放宽：确认率 ≥ 50%、指错 ≤ 5%、硬猜 ≤ 3%）：
  - v2 提示词（叠图字单独一栏、讲清口头用法、高档思考）：确认 11/22、指错 2/13、**硬猜 0/39**、口头用法 30/30。指错和确认率未达标。
  - 发现 v2 有一条写得比标注规则更严，改回后跑 v3：确认 16/22、指错 3/19、硬猜 5/39、口头用法 27/30——确认率上去了，硬猜又回来了。
  - 两版都判「是」且目标一致才采用：确认 10/22、指错 1/11、硬猜 0/39。
  - **结论：Kimi 单独做指代层过不了线**（重测花费约 ¥31）。保守版（v2）不编造，但只认出一半、指错偏多。改为：Kimi 用 v2 做初判，每一条「是」都由 Claude 看原帧逐条复核后才进笔记；同一批题反复调提示词会偏乐观，试点用新题再验。

## 康奈尔笔记格式

格式样稿已定：标题（集 · 主题 · 时间码 · 帧号）+ 依据标记 + 两栏表（提示区一问一个要点；笔记区每条标〔口述〕〔叠图〕〔板书〕〔指代〕〔推断〕和时间码帧号）+ 总结区（通用规则 / 只在本例 / 处世方法）+ 待核。模板见 `康奈尔笔记模板.md`。公开版笔记只引短句，配图用「跳到 B 站原视频那一秒」的链接和自己重画的命盘，不放截图。
