# 任务：讲课视频「指代」裁决

你是视频画面核对员。每题一个子文件夹（题01、题02……），里面有：
- 讲者手部停顿时的整帧截图（文件名含「停顿帧」）和对应的手部放大裁片（含「手部裁片」），可能还有一张手指位置没被挡住时的板面放大裁片（含「板面裁片」）；
- `题目.md`：讲者说的那句话，以及两位核对员（甲、乙）对「讲者说这个词时有没有在指、指的是哪里」的判断，两人意见不同。

画面分四层：黑板手写、后期叠加的电子命盘或图表、烧录字幕、水印。

## 每题要回答
看图后判断甲、乙谁对：讲者说这个词时有没有用手、粉笔或教鞭指着某处；如果有，指的是哪一层、哪一格（第 1 张停顿帧画面横竖三等分，左上 1、右下 9）、那里看得见的字。

## 规则
- 只依据图片看得见的内容；被挡住、看不清就说看不清，不要猜，不要用紫微知识补字。
- 只是口头说「这个人」「这个不好」、手没在指，就是「不是指代」。

## 输出（直接写在回复里，不要写文件，不要运行命令）
```json
{"题": "题01", "裁决": "甲对/乙对/都不对/都对/无法判断", "是指代": "是/否/看不出", "指向": "黑板/叠图/讲义/自己身上/其他/无", "目标文字": "", "格": null, "看到图片": true, "理由": "一句话"}
```
