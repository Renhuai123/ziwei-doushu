# 实验 2 标准答案标注说明（Claude 看原帧出题）

对象：`窗口/<窗口ID>/01–12.jpg`（上方黑条有序号与帧号，下方是原帧，未改动）。
每张图按与 DeepSeek 完全相同的规则（`逐帧提示词-v1.md` 第 1–8 条）填一行，外加一个「把握」字段：

```json
{"f": 帧号, "手可见": true, "触板": "是", "触板区域": 5, "动作": "写", "遮挡区域": [6, 9], "叠图变化": false, "异常": false, "把握": {"触板": "确定", "动作": "确定", "遮挡区域": "不确定"}}
```

- 「把握」只给 触板 / 触板区域 / 动作 / 遮挡区域 四个计分字段打：确定 / 不确定。
- **不确定的字段不计分**，并计入「剔除」，最后公布剔除数与比例。
- 判断时可以前后翻看同一窗口的 12 张（连续动作有助于判断「写」还是「指」），但每一行只写这一张看得见的事实。
- 遮挡区域：讲者身体或手臂挡住了该格里**原本有板书或板面**的部分即算；只是衣角擦边、后面看得见的不算。
- 触板区域：接触点（粉笔尖 / 指尖）所在格；接触点正好在格线上，记接触点像素中心所在格，并把「触板区域」的把握标为不确定。
- 不看讲课内容、不看字幕去推断动作；字幕只当画面的一部分。
- 实验 2 不放探针，「异常」一律 false。

计分（见 Fable 实验 2）：触板、在写（动作 = 写）、遮挡区域三项准确率 ≥ 90%，触板区域 ≥ 80%；遮挡区域按「集合完全相同」计。
