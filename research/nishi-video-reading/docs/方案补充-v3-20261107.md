## 1. 逐帧层：固定 JSON（小考前冻结）

每帧一行，输出不超过约 40 token，不合格自动重发，关闭思考：

```json
{"f": 26401, "手可见": true, "触板": "是|否|未知", "触板区域": 5, "动作": "写|指|擦|讲|其他", "遮挡区域": [4, 7], "叠图变化": false, "异常": false}
```

- 区域按画面 3×3 网格编号 1–9。
- 上文封顶：只带前 2 个窗口的 JSON，加一条不超过 200 字的段摘要。
- 程序算出的手部和板面线索不进提示词，只用来选帧和事后比对。

## 2. 探针（冻结）

- 随机放在约 15% 的窗口里，模型不知道哪一窗有。
- 逐帧层窗口只放两类：换帧（同段 2–5 秒外、手位相近的帧）和遮挡（抠掉一块板书），各占一半。
- 改笔画探针（抹掉或添一笔）归板面层，放在板面裁片上测。
- 帧号在调换之后才按顺序烧上，不能靠帧号发现。
- 同时统计发现率和无探针窗口的误报率。

## 3. 板面状态（定义）

- 程序用像素差加人体遮挡掩膜判定：某区域连续 2 秒以上没有新笔画、也没有被挡，算一个稳定状态。
- 盘画完、擦板前等里程碑做全板转写；中间状态只发变化区域的裁片。
- 每次发 2×2 分块，每块不大于 544×544（DeepSeek 会放大，每 token 对应的像素约少 5.7 倍）；叠图单独裁切。
- 先在 P25、P13 数出状态数，再给板面层报价。

## 4. 指代（坐标）

- 坐标 = 板面状态号 + 盘号 + 宫位或可见文字，允许按顺序写多个目标。
- 取帧：用 whisper 的词级时间戳找到「这里 / 这个 / 这边」，前后各 1 秒，选手停住的帧，加手部裁片和板面裁片。
- 指向被叠图盖住的地方，记「黑板未显示，叠图显示 X（后期层）」，不算已确认。

## 5. 及格线（修订）

| 指标 | 小考门槛 | 试点和全量 |
|---|---|---|
| 已下结论的指代里，指错比例 | ≤ 5% | ≤ 3% |
| 能确认的题里，模型确认的比例 | ≥ 50% | ≥ 70% |
| 逐帧字段准确率（触板、在写、遮挡） | ≥ 90% | ≥ 90% |
| 探针发现率 / 无探针窗误报率 | ≥ 90%（改笔画 ≥ 70%）/ ≤ 5% | ≥ 95% / ≤ 5% |
| 字幕 OCR 逐字准确率 | ≥ 99.5% | ≥ 99.5%；whisper 当第二证人，不一致进疑句 |
| 硬猜、四层标错、拒答 | 只看趋势 | 用 ≥ 600 题证明 ≤ 2%、≤ 1%、≤ 1% |

## 7. Grok 裁决（已预检）

- 实测：Cursor 官方命令行能无人值守调用 Grok 4.7 Extra High。10 道题用掉 Cursor Models 约 1%（订阅内，按需付费未动）；每题 2–3 分钟，三路并行约每小时 45 题。
- 10 题里有 1 题没读到图片：以后每题先校验「是否看到图片」，没看到就自动重跑。
- 其余 9 题和 Codex 旧记录比：7 题一致或相容，1 题部分一致，1 题不一致（Codex 记录不是标准答案，仅作参考）。
- 只裁两家都下了结论、而且冲突的句子级字段；两家都未确认的不裁；板面按格裁。
- 容量不够的部分记「分歧，未裁」，不压回 Claude。
